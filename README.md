# Vital Engenharia e Assessoria

Site institucional da Vital Engenharia e Assessoria, empresa especializada em:

- Projetos arquitetônicos
- Regularização de imóveis
- Assessoria legal
- Habite-se / Certidões
- Financiamento imobiliário CAIXA para pessoa jurídica

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS 4 + shadcn/ui
- **Ícones:** lucide-react
- **Gerenciador:** pnpm

## Funcionalidades

- 27 páginas estáticas geradas em SSG
- Blog com 15 artigos sobre financiamento CAIXA PJ (busca e filtro por categoria)
- Formulário de contato integrado ao WhatsApp
- Carrossel de depoimentos com auto-play
- Design responsivo (preto, branco e dourado)
- SEO configurado

## Scripts

```bash
pnpm dev      # Desenvolvimento em http://localhost:3000
pnpm build    # Build de produção
pnpm start    # Servidor de produção
```
